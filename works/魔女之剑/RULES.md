# Rules

## Context Discipline

- 不要一次性读取整卷或全部正文。
- 先读入口文件，再根据任务读取相关大纲、设定和最近章节。
- 改旧章时只读目标章和相邻章节。
- 续写时默认只读最近 1-3 章。

## Prose Rules

- 默认第三人称有限视角，优先贴近伊凡；必要时切入艾琳娜或塞维林。
- 正文写人物此刻可感知、可判断、可回忆的内容。
- 少用抽象总结，多用动作、声音、气味、温度、重量、材质和空间关系。
- 每章至少推进一个关系、秘密、危险、目标或代价。
- 魔法、真名、黑剑相关场景必须体现代价。

## Prose Bans

正文中避免这些元叙事词：

- 本章
- 上一章
- 下一章
- 作者
- 读者
- 大纲
- 设定
- 剧情
- 主角
- 反派
- 这一卷

这些词可以用于大纲、简报、修改说明，但不要进小说正文。

## File Rules

- 新章节放入 `manuscript/<卷目录>/`。
- 章节命名保持 `第NNN章-标题.md`。
- 写作计划放入 `workbench/`。
- 角色、世界、风格信息放入 `canon/`。
- 分卷和章节计划放入 `outline/`。
- 完成正文后更新 `STATE.md`、`CHAPTERS.md`、`workbench/CHANGELOG.md`。
