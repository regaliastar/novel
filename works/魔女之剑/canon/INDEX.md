# Canon Index

## Files

- `角色设定.md`: character background, relationships, arcs.
- `世界观设定.md`: era, geography, factions, power system, lore.
- `风格指南.md`: tone, POV, pacing, prose rules, taboos.

## Read By Task

- Character scene or relationship conflict: read `角色设定.md`.
- Faction, magic, old gods, geography, or institutional pressure: read `世界观设定.md`.
- Prose style, rewrite, line edit, or chapter drafting: read `风格指南.md`.
