# Context Loading

Use these recipes to keep context small.

## Orientation

Read:

1. `SKILL.md`
2. `references/projects.md`
3. `references/file-layout.md`
4. `works/<title>/PROJECT.md`
5. `works/<title>/STATE.md`
6. `works/<title>/RULES.md`
7. `works/<title>/workbench/TASK.md`

Stop there unless the task needs prose, canon, or outline detail.

## Continue Writing

Read:

1. Orientation files
2. `references/writing-workflows.md`
3. `works/<title>/CONTINUITY.md`
4. `works/<title>/CHAPTERS.md`
5. `works/<title>/workbench/NEXT.md`
6. Relevant outline file from `works/<title>/outline/`
7. Relevant canon index from `works/<title>/canon/INDEX.md`
8. The last 1-3 manuscript chapters, not the entire volume

Then write only the target chapter file and update state files.

## Rewrite Existing Chapter

Read:

1. Orientation files
2. `CHAPTERS.md`
3. Target chapter
4. Previous and next chapter if they exist
5. Relevant canon/rules only if the change touches continuity

Then edit only the requested span.

## Outline Or Planning

Read:

1. Orientation files
2. `CONTINUITY.md`
3. `outline/INDEX.md`
4. Relevant volume outline
5. `workbench/NEXT.md` if planning the next chapter

Avoid reading all manuscript chapters unless the user asks for a full structural audit.

## Continuity Audit

Read:

1. Orientation files
2. `CONTINUITY.md`
3. `CHAPTERS.md`
4. Only chapters related to the suspected continuity issue

Report file paths and precise chapter references.
