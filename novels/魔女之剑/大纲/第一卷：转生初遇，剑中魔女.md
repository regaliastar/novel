# 📝 第一卷：转生初遇，剑中魔女

## 卷概要

主角转世到穷困的边境小村庄，意外捡到被教会封印的魔女之剑，唤醒沉睡的魔女艾莉丝，靠前世农业大学学到的水文地理知识解决村子干旱危机，被村民推举为新村长，正式开启领主+冒险的双重生涯

## 关键事件

- 主角穿越到剑与魔法异世界，附身到刚饿死的边境村穷小子身上
- 在村外废弃山洞捡到被教会封印的黑色长剑，唤醒剑中沉睡的魔女艾莉丝
- 靠前世学到的水文地理知识，观察土壤和植被分布找到地下水源解决村子持续三个月的旱灾
- 被全村村民推举为新村长，获得第一个属于自己的领地
- 教会骑士团前来追查魔女踪迹，主角靠小聪明蒙混过关，和艾莉丝达成合作共识

## 章节列表

### 👍 第一章 刚穿越就饿死？

林恩穿越到埃斯兰大陆边境的红土村，附身到刚饿死的16岁穷小子身上，还没搞清楚状况就差点再饿晕一次，回忆起自己前世是农业大学的学生，有丰富的农业和地理知识。涉及角色：林恩

**关键事件：**
- 林恩在破茅草屋醒来，确认自己穿越到了剑与魔法异世界，回忆起前世的身份和所学知识
- 看到周围土地干裂、植被枯黄的景象，判断村子正遭遇严重旱灾
- 找村长打听情况，得知村子已经遭遇三个月旱灾，颗粒无收

### 📝 第二章 后山的黑色怪剑

饿到发昏的林恩打算去后山找野果充饥，自己观察野兔子的踪迹躲开了教会巡逻队，在废弃山洞里发现了一柄插在石头上的黑色长剑，刚碰到剑就听到剑里传来暴躁的女声吐槽。涉及角色：林恩

**关键事件：**
- 林恩顺着野兔子活动的痕迹往后山走，发现并躲开了教会骑士团的巡逻队
- 在废弃山洞里发现被封印的黑色长剑，剑身上刻满了黑暗魔法纹路
- 指尖碰到剑身时，剑中封印的艾莉丝主动传音吐槽他手脏

### 📝 第三章 剑里住了个傲娇魔女

林恩观察剑周围石头上的特殊纹路，在艾莉丝的暗中指导下成功拔下黑剑，唤醒了被封印在剑里的上古黑暗魔女艾莉丝，艾莉丝本想吓唬林恩，反被林恩的吐槽怼得哑口无言，只能暂时和林恩绑定。涉及角色：林恩、艾莉丝

**关键事件：**
- 林恩观察固定黑剑的石头上的封印纹路，结合艾莉丝的小声指导找到解锁方法，成功拔出黑剑
- 艾莉丝从剑里现身，本想放黑暗魔法吓唬林恩
- 林恩毫不害怕反而吐槽艾莉丝的哥特裙沾了灰，气得艾莉丝跳脚

### 📝 第四章 全村的希望？

林恩带着黑剑回到村子，正好碰到村长老伯带着村民摆祭坛求雨，得知求了一个月毫无成效，林恩主动提出自己能找到地下水源，所有人都以为他饿傻了。涉及角色：林恩、艾莉丝、红土村村民

**关键事件：**
- 林恩回到村子，撞见村长带领村民在晒谷场求雨
- 林恩主动表示自己能找到水源，被村民当成饿昏头说胡话
- 艾莉丝在剑里吐槽林恩爱出风头，却悄悄用魔力帮他提神

### 📝 第五章 地下暗流的位置

林恩带着半信半疑的村民在村子周围勘探，靠前世学到的水文知识观察土壤湿度、耐旱植物的分布规律，很快确定了地下暗流的位置，艾莉丝暗中用魔力辅助确认，挖掘没多久就碰到了湿润土层。涉及角色：林恩、艾莉丝、红土村村民

**关键事件：**
- 林恩观察不同区域的土壤颜色、硬度，以及耐旱杂草的分布，在村西头空地确定打井位置
- 村民半信半疑开始挖掘，挖了三米就挖出了湿润的泥土
- 所有人都对林恩的判断惊讶不已，态度从不屑转为期待

### 📝 第六章 出水了！

挖到第五米时井里涌出清澈地下水，全村人欢呼雀跃，林恩结合地形走向判断上游有更大的水源，可以修水渠灌溉农田，村长当场决定举办庆功宴。涉及角色：林恩、艾莉丝、红土村村民

**关键事件：**
- 井中喷出大量地下水，彻底解决村子三个月的旱灾
- 林恩根据附近的地势起伏和植被分布，判断上游山谷有更大的水源，可以修水渠覆盖所有农田
- 村长激动地宣布当晚举办全村庆功宴，所有人都围上来感谢林恩
